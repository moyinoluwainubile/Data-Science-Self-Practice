# Data Science — Self Practice

This folder contains my personal practice work as I learn Data Science from the ground up.

The purpose of this space is to practise, experiment, make mistakes, test ideas, and strengthen my understanding beyond the guided lessons and assigned practical tasks in the 24-week Data Science programme.

This is not a collection of perfect code. It is a record of learning in progress.

## Why This Folder Exists

Learning a concept is only the beginning.

I use this space to:

- Re-write concepts in my own code
- Experiment with Python syntax and behaviour
- Test what I think the code will do before running it
- Practise concepts repeatedly
- Try variations of examples from the lessons
- Make mistakes and learn from the resulting errors
- Build small programs from what I have learned
- Strengthen problem-solving and programming habits
- Keep evidence of my progress as I learn

The goal is understanding through practice, not simply completing lessons.

## My Current Workflow

My current learning workflow is:

**Learn → Practise → Run → Check → Correct → Push to GitHub**

I primarily use **VS Code** for writing and running my Python code.

After completing practical work, I push the finished work to GitHub as part of building a public record of my learning journey.

## Practice Principles

### 1. Understand Before Moving On

I am not trying to rush through the programme.

If a concept does not make sense, I will spend time working through it until I understand it.

### 2. Practise What I Learn

Every major concept should eventually appear in actual code.

### 3. Make Mistakes

Errors are part of the learning process.

I will deliberately experiment, make mistakes, read the error messages, and correct my code.

### 4. Predict Before Running

Whenever possible, I will try to predict what my code will produce before running it.

Then I will compare my prediction with the actual result.

### 5. Build, Don't Just Watch

The objective is not to become good at watching programming tutorials.

The objective is to become capable of writing, understanding, debugging and explaining code.

### 6. Keep Evidence

Completed practice will be kept in this repository and pushed to GitHub as I progress.

This creates a record of what I have actually practised and built.
