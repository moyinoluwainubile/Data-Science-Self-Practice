### 2. Projects

This section highlights applications I have built while developing my programming skills.

#### Number Guessing Game

An interactive number guessing game built with Python and Streamlit, featuring single-player and multiplayer modes.

**Features:**

* Single-player gameplay against a randomly generated secret number.
* Multiplayer rooms that allow players to join from different devices.
* Three difficulty levels: Easy, Medium, and Hard.
* Turn-based multiplayer gameplay and score tracking.
* Attempt limits, hints, and round-based replay.
* Firebase Firestore integration for shared multiplayer game data.
* Online deployment using Streamlit.

**Play online:** https://numguess.streamlit.app/

**Source code:** `number_guessing.py`
